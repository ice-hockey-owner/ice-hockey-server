Ice Hockey Online – UI V3

Features:
- Friends list limit: 250
- Red request badge
- Persistent friend chat history while server is running
- Image/video/audio chat attachments
- Rematch challenge with Accept/Reject
- Play Again quick matchmaking after a loss
- Desktop cursor movement controls your player
- Mobile touch/drag controls your player
- 3:00 timed matches
- Poki SDK integration

Run:
npm install
npm start
Then open http://localhost:3000

Put your real profile images in assets/images/IdPhotos.
